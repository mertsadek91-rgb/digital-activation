## Facts

- **`D:\Cloude\digital-activation\Old Website\` (372 MB)** contains:
  - the SQL dump (`Full Backup/…sql.gz`)
  - the full site tarball (`…tar.gz`)
  - the XML export
  - design notes and screenshots
- **`.cache/` (128 MB)** contains extracted `wp-content/uploads`, processed media
  and scratch files from tests.
- **Neither folder is in Git.** Both are gitignored, neither has ever appeared in
  history, and neither is in any build context. Git worktrees do not contain them.
- **They are not encrypted.** They sit on a working laptop, next to a `.env` that
  holds live staging credentials.

## Severity

MEDIUM. The data is sensitive, but it has no path to the new application or to
the internet. The machine itself is the only exposure: loss, theft, sync to a
cloud drive, or an accidental copy.

## Remediation

Follow the retention recommendation in CURRENT_STATE_AUDIT.md:

- keep only what migration still needs
- hold it in an encrypted archive
- destroy it after cutover
