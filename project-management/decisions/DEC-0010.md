# DEC-0010 — Governance records are Markdown; indices, state and dashboard are generated

## Context and decision

Hand-maintained JSON indices drift from the task files the first time someone forgets one of eight update steps. tools/sync.mjs derives TASK_INDEX.json, PROJECT_STATE.json, AGENT_STATE.json, MANAGER_STATE.json, the other indices, the agent/manager profiles and dashboard/data.js from the Markdown sources and PERMISSIONS.json, validates the constitution’s rules, and logs status transitions. The dashboard is static HTML that reads data.js, so it works from file:// with no server.

## Current standing

Options considered: (A) hand-kept JSON — rejected, cannot guarantee freshness; (B) a small web app with a database — rejected, disproportionate and a second source of truth; (C) generated from Markdown — proposed.
