# DEC-0002 — Payments: Stripe + PayPal; bank transfer / crypto only as a last resort

## Context and decision

The legacy manual-only gateway is the plan’s explanation for the 31.9% cancellation rate. Build behind an abstract provider interface; Paddle / Lemon Squeezy (merchant of record) is the fallback if Stripe refuses the Turkish entity.

## Current standing

**Reassessment open.** Commit 3cf6c0a lets production boot on bank transfer alone, PayPal is not built, and there is no provider interface — checkout calls Stripe inline. This does not by itself contradict the decision (the manual method remains a fallback), but launching on bank transfer alone would. See CONSENSUS-0001.
