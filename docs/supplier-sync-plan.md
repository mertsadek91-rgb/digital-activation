# شيت المورّد + المنتجات بالذكاء الاصطناعي (CR-0004)

الحالة: مُنفَّذ في الكود، غير مرفوع إلى git بعد، وبانتظار المراجعات المستقلة وقرارات المالك أدناه.
السجلات: SIG-0006 ← CR-0004 ← TASK-0111 (القراءة)، TASK-0112 (الربط والأسعار والنفاد)، TASK-0113 (المحتوى بالذكاء الاصطناعي)، TASK-0114 (صورة البطاقة).

## قرارات المالك (2026-10-05)

1. السعر = التكلفة × 1.5 افتراضياً (نسبة ربح على التكلفة، قابلة للتغيير، ولكل متغيّر نسبة خاصة اختيارية).
2. المنتج المشطوب في الشيت يتحول إلى «أخبرني عند التوفر». باقي المنتجات تبقى متوفرة.
3. صورة المنتج بنفس بطاقة الموقع القديم.
4. الذكاء الاصطناعي عبر حساب OpenCode، والنموذج يُختار من قائمة النماذج في الحساب.

## كيف يعمل

**القراءة.** Google Sheets API بمفتاح، كل ساعة وبزر «اقرأ الشيت الآن». تُقرأ القيم والخط على كل خلية والخلايا المدمجة. الأعمدة تُعرف بعناوينها لا بمكانها. إذا تغيّر شكل الشيت أو نقص أكثر من نصف الأسطر فجأة، تُرفض القراءة ولا يتغير شيء.

**الهوية.** كل سطر يُعرف باسمه بعد توحيد المسافات وحالة الأحرف. إضافة سطر في الوسط لا تؤثر. السطر الذي يختفي يُعلَّم «اختفى» ولا يُحذف، فيبقى ربطه إن عاد.

**السجل.** كل قراءة تُحفظ مع ما تغيّر في كل سطر: السعر، التوفر، الفئة، الضمان، الملاحظات، سطر جديد، اختفاء، عودة. كل ربط وكل سعر طُبّق وكل تغيير توفر يُكتب في سجل التدقيق المتسلسل.

**الربط.** في تبويب «الربط» يظهر كل متغيّر من منتجاتنا مع أقرب 3 أسطر من الشيت. تختار السطر مرة واحدة ويُحفظ. لا يُربط شيء تلقائياً.

**الأسعار.** المقترح = التكلفة × (1 + النسبة). التقريب اختياري: إلى السنت، أو ينتهي بـ .99، أو إلى الدولار. لا يتغير أي سعر دون ضغطك على: منتج واحد، أو المحدد، أو الكل. الخادم يعيد حساب كل سعر بنفسه. التغييرات الأكبر من 30% تحتاج تأكيداً مع «الكل»، ولا يُقبل سعر أقل من التكلفة.

**النفاد.** إذا شُطب اسم السطر أو اختفى، يصبح المتغيّر المربوط غير قابل للشراء. صفحة المنتج تعرض «أخبرني عند التوفر» مع رسالة «نفد حالياً، ويعود قريباً». السلة والدفع يرفضانه. عند عودته يُرسل بريد لمن طلب الإشعار تلقائياً.

**المحتوى.** عبر OpenCode Zen. تحمّل قائمة النماذج من حسابك وتختار واحداً، والاتصال يُضبط حسب نوع النموذج ويمكن تغييره. يكتب النموذج بالعربية والإنجليزية: الوصف المختصر، عنوان ووصف SEO، الكلمات المفتاحية، والمحتوى بكتل الموقع. الكتل هي الجواب الأول، العناوين، النص، الخطوات، جدول المواصفات، والأسئلة الشائعة. يستخدم حقائق المنتج فقط ويُمنع من اختراع الميزات. تراجع النص ثم تحفظه بنفسك عبر نفس محرر المنتج، فيبقى التنظيف وفحص الجاهزية والسجل كما هي.

**إنشاء منتج من سطر.** زر «أنشئ منتجاً» على أي سطر غير مربوط. يقترح النموذج الاسمين والرابط والمدة والأجهزة وطريقة التفعيل، والسعر من التكلفة والنسبة. تراجعها، فيُنشأ المنتج كمسودة ويُربط بالسطر، ثم تنتقل لكتابة محتواه.

**صورة البطاقة.** تُرسم بنفس قالب الموقع القديم: الشعار، وشريط المدة أو الأجهزة، والموجة، والاسم على لون العلامة، وشارتا «تسليم فوري» و«مفتاح أصلي». اللون يُستخرج من الشعار. النص يُقترح من البيانات أو من الذكاء الاصطناعي. تعاين ثم تحفظ في صور المنتج عبر نفس مسار رفع الصور.

## المطلوب من المالك

المفاتيح في متغيرات بيئة خدمة الـ API على Coolify، لا في المحادثة:

| المتغير               | الإعداد                                                                        |
| --------------------- | ------------------------------------------------------------------------------ |
| GOOGLE_SHEETS_API_KEY | Google Cloud ← فعّل Google Sheets API ← أنشئ API key وقيّده على Sheets API فقط |
| OPENCODE_API_KEY      | مفتاح حسابك على opencode.ai/zen                                                |

قرارات تحتاج موافقتك:

1. **ملفات خط Tajawal** للبطاقة: `Tajawal-Bold.ttf` و`Tajawal-ExtraBold.ttf` مع `OFL.txt` من مستودع Google Fonts، رخصتها مفتوحة. بدونها تُرسم البطاقة بخط الخادم الافتراضي، وقد لا يدعم العربية.
2. **تطبيق الـ migration على قاعدة staging** قبل دمج الكود، لأن Coolify لا يطبّقها تلقائياً. التغيير إضافي فقط: جداول جديدة وعمود بقيمة افتراضية false.
3. **رفع العمل إلى git وفتح PR.**
4. استخدام شعارات العلامات التجارية في الصور قرار قانوني يعود لك.
